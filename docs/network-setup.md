# 客户配置网口 IP

两条入口共用一份配置，保存到设备 NVS，断电保留。当前仅提供 IPv4 静态地址，
不要求客户安装串口工具或修改配置文件。网口 IP 配置的是 ESP32 自己的地址；新增的“交换机管理连接”区填写交换机的另一管理地址。
SSH / Telnet 参数可通过热点或网口页面与网口、MQTT 参数一起保存，详见 [交换机管理连接配置](switch-connection.md)。
SSH 配置会启动 ESP 网口直连登录；Telnet 目前仅保存配置。SSH 登录后自动进行真实 H3C 采集与受保护的 BDI 处置，日志和小模型推理均在 ESP 完成。
正式运行无需 USB 网关。可选 MQTT 用于远程监视与归档，断开后台不影响本机工作；旧 USB 链路只保留作显式实验兼容。

## 手机连接 Wi-Fi 热点（推荐）

默认上电关闭所有配置入口，只有按住 BOOT 三秒才开启配置窗口，在手机 Wi-Fi 设置中连接免密码热点
`ESP-Config-…`，等待“登录网络”或配置页提示。手机提示没有互联网时选择继续连接。
没有弹出时，手动打开 `http://esp.setup`。当网口位于 `192.168.4.0/24` 时，
热点会避开网口网段，使用 **`http://192.168.5.1`**；其他配置下优先使用
`192.168.4.1`，具体地址以所连热点的网关为准，也保留在本机启动日志中。

页面修改的是网口 IP，热点地址在当前窗口内保持不变。禁止将网口设置到热点同网段，
以免两个接口路由冲突。保存成功后绿灯亮三秒，随后关闭热点、蓝牙配置连接和 HTTP 服务；未保存时热点十分钟后关闭。按住 BOOT 三秒可重新开启。
自动弹窗由手机系统决定；设备提供 DHCP Portal 提示、DNS 引导和 HTTP 重定向，
没有弹窗时仍可手动访问。请在 Wi-Fi 设置中连接，不需要蓝牙配对。

GPIO21 板载 RGB 灯：蓝灯慢闪表示等待连接，蓝灯快闪表示手机已接入热点，
绿灯亮三秒表示保存成功，红灯快闪三秒表示参数、保存或热点启动失败，
配置窗口关闭后熄灯。蓝牙保存同样提供成功和失败灯提示。
免密码热点仅用于现场配置，配置窗口内附近设备可以修改参数。

## 方式一：网口连接电脑

先按住 BOOT 三秒开启配置窗口。以下地址适用于出厂默认配置；已修改时使用实际网口 IP，并为电脑选择同网段中未占用的其他地址。

1. 用网线连接设备和电脑，设备另外供电（网线供电需实际硬件支持）。
2. 初次使用，把电脑的有线网卡设为 `192.168.10.3`，子网掩码 `255.255.255.0`。
   直连配置时电脑网卡可不填网关、DNS。
3. 浏览器打开 `http://192.168.10.1`，填写设备 IP、掩码、网关、DNS，以及交换机和 MQTT 参数，点击底部唯一的“保存全部配置”。
4. 一秒后设备切换到新 IP，三秒后配置入口关闭。将电脑改到同网段或接入目标网络；需再次访问配置时，按住 BOOT 三秒后使用新 IP。

默认设备 IP 是 `192.168.10.1/24`，网关为 `192.168.10.10`，DNS 为 `192.168.4.254`。
已保存到 NVS 的配置优先于出厂默认值，更新固件不会覆盖已有配置。
不用网关、DNS 时可分别填 `0.0.0.0`。保存前会检查掩码连续性、网络/广播地址及网关同网段。
初次直连不能依赖 DHCP 自动获得电脑地址，因此步骤 2 必需。
如果忘记设备 IP，可用蓝牙读取和修改，不需要清空设备。

## 方式二：蓝牙连接配置

1. 按住设备 BOOT 键三秒开启配置窗口，在十分钟内打开控制台的“网口 / 蓝牙配置”页。
   不要按复位组合进入下载模式。保存成功后三秒自动关闭，需再次按键才能重新配置。
2. 点击“蓝牙连接设备”，选择 `ESP-Config-…`。页面自动读取设备已保存的地址。
3. 修改 IP、掩码、网关、DNS，点击保存。错误会显示在页面内，合法配置才会落盘。

不需要到操作系统蓝牙设置中预先配对。使用支持 Web Bluetooth 的 Chrome / Edge，
页面需从 `http://localhost:4173/device/network.html`、`http://127.0.0.1:4173/device/network.html`
或 HTTPS 打开。普通局域网 HTTP 页面不能调用 Web Bluetooth；iPhone Safari 不支持此入口。
可以使用客户电脑完成蓝牙配置。

配置窗口内附近设备可进行配置，不提供账号和配对密码；现场部署应由安装人员控制配置窗口。
窗口关闭后，热点、DNS 引导、HTTP 服务和 BLE 广播全部停止，现有 BLE 连接断开；网口继续使用保存的参数。

## 硬件接入状态（必须先核对）

当前按用户确认的 **Waveshare ESP32-S3-ETH** 启用板载 W5500：SCLK=13、MISO=12、MOSI=11、CS=14、INT=10、RST=9。
引脚依据 [厂商官方资料](https://docs.waveshare.com/ESP32-S3-ETH/Development-Environment-Setup-Arduino#10_eth_dhcp)。
PlatformIO 仍使用 ESP32-S3 通用构建目标；更换硬件时，必须修改 `platformio.ini` 的以下 GPIO 定义：

```ini
  -D ESP_ETH_W5500=1
  -D ESP_ETH_SCK=<实际时钟GPIO>
  -D ESP_ETH_MISO=<实际MISO_GPIO>
  -D ESP_ETH_MOSI=<实际MOSI_GPIO>
  -D ESP_ETH_CS=<实际片选GPIO>
  -D ESP_ETH_IRQ=<实际中断GPIO>
  -D ESP_ETH_RST=<实际复位GPIO或-1>
```

GPIO 0 用于 BOOT 配置窗口，GPIO 19/20 用于当前原生 USB，不应分配给网口。
驱动初始化成功才启动设备上的 HTTP 配置服务。其他网口芯片需要对应驱动，不能直接套用 W5500 参数。
本机日志会记录 `[NETWORK] ip=… ethernet=ready/unavailable`。
`ready` 表示驱动初始化成功，不代替网线链路、交换机连通性和地址冲突检查。

BLE 服务 UUID：`68b10001-7d85-4f37-b71b-58d52ce12000`；可读写特征：
`68b10002-7d85-4f37-b71b-58d52ce12000`。
配置格式为 `IP|MASK|GATEWAY|DNS\n`，页面按 20 字节分片写入；设备收到换行才整体校验和保存。
读取返回已保存配置，处理中为 `SAVING`，失败为 `ERROR: …`。蓝牙保存成功只代表配置落盘，
物理网口是否可用还需核对硬件、驱动和链路。

## 开发检查

修改网页后运行 `python3 tools/embed_network_page.py`，同步到 `src/generated/network_page.h` 和 `src/generated/archive_page.h`，不手动编辑生成文件。
`frontend/device/network.html` 不依赖 CDN，网口直连时可离线使用。

```sh
c++ -std=c++11 test/network_settings.cpp -o /tmp/esp-network-settings-test
/tmp/esp-network-settings-test
npm --prefix frontend run build
PLATFORMIO_CORE_DIR="$PWD/.pio-core" ~/.platformio/penv/bin/pio run
```

实物验收需在对应硬件上检查：网线直连访问、蓝牙读取与修改、非法地址拒绝、
断电重启恢复、配置窗口关闭与重新开启、改 IP 后访问，以及网口采集、BDI 与本机日志持续工作。

## 只看 TF 记录

连续短按 BOOT 三次开启独立只读日志分析页。手机连接 ESP-Logs 热点，查看故障分析、原始日志、处置过程及当前 AI / BDI / SSH / MQTT 状态；无需进入配置或保存参数。未自动弹窗时打开 http://esp.setup。查看模式拒绝配置接口，十分钟后自动关闭。详细用法与容量循环清理规则见 [TF 卡故障记录](tf-fault-journal.md)。

## SSH 自动配对与可选 MQTT

设置页没有公钥或指纹输入框。首次连接由 ESP 自动保存交换机主机公钥并在发送密码前完成配对；以后逐次校验。页面只读显示可信指纹与 `unpaired / trusted / mismatch / error`。发现换钥时停止登录，不会悄悄覆盖旧钥；在可信现场确认交换机变更后，长按 BOOT 开启设置，点击“重新配对当前交换机公钥”。保存 IP 或 MQTT 不会清空主机钥。

MQTT 默认关闭，固件自带可选连接能力，默认单层主题前缀 `esp-switch`；已保存的旧前缀保留。填写本地 Broker 地址与独立设备账号，随其余参数一起保存。启用后上报 `status`、`report`、`availability`，不会从 MQTT 接受任意交换机命令。软件后台使用 `config/native.json`，后台 AI 可另配 Ollama，默认关闭。

长按设置与三击日志是两个窗口：日志窗口不能重新配对、修改网络或保存凭据。设置页内的“查看故障与 AI 解释”链接只是查看，不需要点击保存。
