交换机管理连接 · SSH / Telnet

此栏用于配置交换机 SSH / Telnet。请连接 ESP 配置热点或通过网口打开设备 IP；电脑上的蓝牙入口目前仅保存网口 IP。

网线接入后，填写交换机的管理地址；此地址与 ESP 网口 IP 不同。连接参数与网口参数一起保存。

SSH 配置保存后，ESP 将通过网口尝试登录交换机。登录后每 5 秒 ping 一次管理 IP，连续 3 次失败告警、2 次成功确认恢复。心跳不代表设备业务正常；Telnet 尚不支持。

可信指纹：尚未配对

首次连接时 ESP 自动保存交换机主机公钥，之后逐次校验，无需输入公钥或指纹。检测到换钥时停止登录；确认交换机已更换或重新配置后，可在现场重新配对。

密码保存在设备 NVS 中，不通过读取接口回显。当前配置热点与 HTTP 未加密，请在可信现场配置。尚不支持密钥认证、SNMP 或串口管理，页面不提供这些选项。

交换机只读查询

使用 ESP 已登录的 SSH 会话，一次查询一项。结果为交换机原始输出；持续监测、分析和 BDI 处置由 ESP 本机完成。

连接 ESP 配置页且 SSH 已登录后可查询。

后台监视 · 可选 MQTT
连接设备热点或网口后读取参数，与其他配置一起保存。
MQTT 连接参数
随全部配置一次保存。启用后通过网口上报设备状态、现场日志与本机分析结果，后台可监视和归档。未启用或后台离线时，ESP 仍独立监测、分析与处置。当前连接为局域网 TCP。
TF 卡故障记录
插入 TF 卡后，正式版由 ESP 本机采集并保存运行、SSH 和 BDI 记录。连接设备配置页可查看卡状态。
查看故障与 AI 解释（无需保存配置）
连按三下 BOOT 可单独打开只读查看入口。现场记录位于 esp-native 文件夹，按容量循环保留，不依赖 USB 或电脑。未插卡或卡异常不会中断监测；记录可能丢失，状态会显示丢弃数量。BDI 按实际交换机证据处置业务口，保护管理连接；处置结果须等待后续采集验证。请勿在写入时拔卡。
尚未连接
蓝灯慢闪：等待连接；蓝灯快闪：手机已接入；绿灯亮 3 秒：保存成功，随后自动关闭配置；红灯快闪：配置失败。配置断电保留。热点不提供互联网，手机提示时请选择继续连接。
